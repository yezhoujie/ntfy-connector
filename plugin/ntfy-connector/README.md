# ntfy-connector (plugin)

The Claude Code plugin that exists today **is** the `agent-ntfy` skill in `skill/agent-ntfy/`, installed through the marketplace of the index repository (`claude plugin marketplace add yezhoujie/agent-remote-communication-skills`, then `claude plugin install agent-ntfy@agent-remote-communication-skills`; README §3).
This directory is reserved for a future plugin packaging of ntfy-connector with a hooks module, distinct from that skill.
Empty for now — nothing here is published or installable yet.
